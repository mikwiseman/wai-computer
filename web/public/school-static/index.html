Curiosity is the starting point

From playing with technology
to creating with it.

Wai School is a project-based learning programme. Children work with a mentor in live online lessons, use AI tools, and build websites, games and small applications around their own interests.

They practise explaining an idea, asking useful questions, testing the result and improving it. The project grows with them — one working version at a time.

The four-week starting journey

An idea takes shape.

Real tools. Small steps.
A project worth showing.

  1. 01

    Imagine & build

    Make the first version.

    Choose an idea, describe it clearly to AI and create a first website or interactive prototype.

    Takeaway: something you can open.

  2. 02

    Remember & improve

    Keep the good ideas.

    Give the project useful context, save versions and learn to explain what should change.

    Takeaway: a project with a history.

  3. 03

    Connect & test

    Make it do more.

    Explore AI roles and simple data storage. Test interactions, spot mistakes and refine the experience.

    Takeaway: a more capable prototype.

  4. 04

    Publish & share

    Say “I made this.”

    Prepare a demonstration, publish an appropriate project version and explain how it works.

    Takeaway: a project to present.

This is the starting curriculum, adapted to the child's age, pace and project. Later modules continue the work; not every project uses every tool.
