How to install

  1. Download the file using a button above.
  2. Tap the downloaded file.
  3. Your phone will ask to open it in Minecraft. Tap Yes.
  4. Minecraft installs it automatically. Look for Imported ✅
⚡ For a mod (.mcaddon): open a world → Edit → Behavior Packs → Activate. The mod needs this to appear!
🧍 For a skin (.mcpack): open the Dressing Room from the main menu → My Skins → select the new one.
